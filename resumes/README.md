# Resumes Directory

Place your master resume in PDF format in this directory:
e.g. `resumes/Harsh_Parmar_Software_Engineer.pdf`

Update the `resume_path` in `config/profile.yaml` to point to your PDF resume:
```yaml
personal_info:
  resume_path: "resumes/Harsh_Parmar_Software_Engineer.pdf"
```

The applier agent will automatically locate and attach this file to Greenhouse, Lever, and other ATS forms that contain file upload fields.
